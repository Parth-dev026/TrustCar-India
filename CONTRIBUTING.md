# Contributing

Thanks for considering contributing to TrustCar-India.

## Good first contributions
- Improve documentation clarity.
- Add credible, dated research sources.
- Suggest accessible UX improvements.
- Add tests for pricing, booking conflicts, and state transitions.
- Report reproducible bugs with fictional demo data.

## Workflow
1. Open an issue describing the problem or proposed change.
2. Keep changes small and focused.
3. Never include real personal information, identity documents, secrets, or payment details.
4. Add or update tests for code changes.
5. Explain what changed and how it was tested in the pull request.

## Project boundaries
This is an educational prototype. Do not add real payment processing, identity-document collection, or real rental fulfilment without explicit project review and appropriate legal/security assessment.

By contributing, you agree to follow the Code of Conduct.
