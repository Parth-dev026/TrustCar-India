# User flows

## Renter
1. Open demo listings and apply filters.
2. Select a listing and review availability, vehicle details, itemised estimate, terms, and cancellation conditions.
3. Submit a booking request.
4. View requested, accepted, declined, or cancelled status.
5. For an accepted demo booking, review pickup checklist and add observations.
6. At return, review the return checklist alongside pickup notes.
7. If needed, open a complaint ticket and follow its status timeline.

## Vehicle owner
1. Open the owner dashboard.
2. Create or edit a fictional vehicle listing.
3. Review booking dates and renter request details limited to demo information.
4. Accept or decline a request with a recorded reason.
5. Complete pickup and return checklist records.
6. Review linked support tickets and their status.

## Administrator
1. Review open demo tickets.
2. Check booking and handover timeline.
3. Add a neutral internal note and change ticket status.
4. Keep a timestamped history of changes.

## UX principles
- Always distinguish estimate from final charge.
- Explain status labels in plain language.
- Never imply a deposit/refund occurred in real life.
- Avoid revealing another user's unnecessary personal data.
- Give users a way to correct mistakes and see what changed.
