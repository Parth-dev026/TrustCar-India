# Security policy

## Scope
This repository is an early-stage educational prototype and is not intended to manage real rentals, identity data, or payments.

## Reporting a concern
Please do not publish exploit details or sensitive information in a public issue. Contact the repository owner through the private contact options available on their GitHub profile and include:
- A concise description of the issue
- Reproduction steps using fictional data
- Potential impact
- A suggested fix, if known

Do not include passwords, tokens, identity documents, financial data, or private user information.

## Current limitations
There is no production service or supported production deployment yet. Do not use the prototype for real transactions.
